# Brainstorm — Day 29 음정 듣기 퀴즈

## MUST (꼭 필요한 기능)
1. **음 재생 + 정답 선택**: 사용자가 "▶ 듣기" 버튼을 누르면 정답 음(또는 화음)이 재생되고, 보기 버튼(도·레·미 ...) 중 하나를 눌러 답을 제출. 즉시 정/오 피드백.
2. **난이도 3단계**: 3음(도·미·솔), 5음(도·레·미·솔·라), 7음(도·레·미·파·솔·라·시). 선택지 개수가 함께 바뀜.
3. **모드 3종 전환**: 한 음(단음 인식), 두 음 비교(같다/높다/낮다), 세 음 코드(어떤 3개?). 한 화면에서 라디오 그룹으로 전환.
4. **점수·정답률 누적 + 리셋**: 시도 횟수, 정답 수, 정답률 % 라이브 표시. 리셋 버튼 1개.
5. **다시 듣기 / 다음 문제**: 정답을 본 후 같은 문제 재생을 한 번 더 들을 수 있고, "다음 문제"로 새 문제를 뽑음.

## SHOULD (있으면 좋은 기능)
1. **건반 시각화**: 1옥타브 미니 건반 SVG. 정답 공개시 해당 음이 깜빡임 → 음과 위치를 함께 학습.
2. **음 길이/템포 조절**: 음 재생 길이를 짧음/보통/김(0.6/1.0/1.5초) 중 선택. 듣기 어려운 학생을 위한 접근성.

## MUST NOT (절대 금지)
1. **서버·DB 점수 저장**: 토픽 명시적 배제. 휘발성만.
2. **로그인/계정·개인 식별 정보 수집**: 1:1 환경, 익명 사용.
3. **광고·외부 트래커·analytics SDK**: 교실 환경 부적합.
4. **마이크 입력으로 음높이 평가**: scope creep. 듣기만, 부르기는 후속 토픽에 양보.
5. **PWA·offline cache·service worker**: 단순 토픽 오버킬.

## 사용자 흐름
1. 페이지 진입 → 짧은 안내 + "▶ 시작" 버튼 (오디오 컨텍스트 unlock).
2. 시작 후: 상단 컨트롤 패널(난이도/모드/길이/리셋) + 가운데 문제 카드(▶ 듣기 + 보기 버튼) + 하단 점수·미니 건반.
3. 답 클릭 → 정/오 피드백 + 정답 강조(건반) + "다시 듣기" / "다음 문제".
